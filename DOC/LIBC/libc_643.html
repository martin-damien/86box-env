_read

Syntax

 
#include <io.h>

ssize_t _read(int fildes, void *buf, size_t nbyte);

Description

This is a direct connection to the MS-DOS read function call, int 0x21, %ah = 0x3f. No conversion is done on the data; it is read as raw binary data. This function can be hooked by the See section File System Extensions. If you don't want this, you should use See section _dos_read.

Return Value

The number of bytes read.

Portability

ANSI/ISO C No
POSIX No
