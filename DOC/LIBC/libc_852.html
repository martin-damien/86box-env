vfscanf

Syntax

 
#include <stdio.h>

int vfscanf(FILE *file, const char *format, va_list arguments);

Description

This function scans formatted text from file and stores it in the variables pointed to by the arguments. See section scanf.

Return Value

The number of items successfully scanned.
