_dos_unlock

Syntax

 
#include <io.h>

_dos_unlock(int fd, long offset, long length);

Description

Removes an advisory lock to the specified region of the file.

Return Value

Zero if the lock was removed, nonzero otherwise.

Portability

ANSI/ISO C No
POSIX No
