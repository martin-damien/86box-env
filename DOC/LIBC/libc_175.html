_dos_lock

Syntax

 
#include <io.h>

int _dos_lock(int fd, long offset, long length);

Description

Adds an advisory lock to the specified region of the file.

Return Value

Zero if the lock was added, nonzero otherwise.

Portability

ANSI/ISO C No
POSIX No
