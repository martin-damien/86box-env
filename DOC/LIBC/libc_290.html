endgrent

Syntax

 
#include <grp.h>

void endgrent(void);

Description

This function should be called after all calls to getgrent, getgrgid, or getgrnam.

Return Value

None.

Portability

ANSI/ISO C No
POSIX No

Example

See section getgrent.
