sqrt

Syntax

 
#include <math.h>

double sqrt(double x);

Description

This function computes the square root of x.

Return Value

The square root of x. If x is negative or a NaN, the return value is NaN and errno is set to EDOM.

Portability

ANSI/ISO C C89; C99
POSIX 1003.2-1992; 1003.1-2001
