ffs

Syntax

 
#include <string.h>

int ffs(int _mask);

Description

This function find the first (least significant) bit set in the input value.

Return Value

Bit position (1..32) of the least significant set bit, or zero if the input value is zero.

Portability

ANSI/ISO C No
POSIX No

Example

 
ffs(0) = 0
ffs(1) = 1
ffs(5) = 1
ffs(96) = 6
