setdate

Syntax

 
#include <dos.h>

void setdate(struct date *ptr);

Description

This function sets the current time.

For the description of struct date, see getdate. Also see settime.

Return Value

None.

Portability

ANSI/ISO C No
POSIX No

Example

 
struct date d;
setdate(&d);
