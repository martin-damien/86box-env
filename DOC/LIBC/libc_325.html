fileno

Syntax

 
#include <stdio.h>

int fileno(FILE *file);

Description

This function returns the raw file descriptor number that file uses for I/O.

Return Value

The file descriptor number.

Portability

ANSI/ISO C No
POSIX 1003.2-1992; 1003.1-2001
