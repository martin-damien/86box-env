isxdigit

Syntax

 
#include <ctype.h>

int isxdigit(int c);

Description

Tells if c is a valid hexadecimal digit or not. This includes [0-9a-fA-F].

Return Value

Nonzero if c is a hex digit, else zero.

Portability

ANSI/ISO C C89; C99
POSIX 1003.2-1992; 1003.1-2001
