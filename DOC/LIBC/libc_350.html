free

Syntax

 
#include <stdlib.h>

void free(void *ptr);

Description

Returns the allocated memory to the heap (see section malloc). If the ptr is NULL, free does nothing.

Return Value

None.

Portability

ANSI/ISO C C89; C99
POSIX 1003.2-1992; 1003.1-2001

Example

 
char *q = (char *)malloc(20);
free(q);
