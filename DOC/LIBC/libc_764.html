strlen

Syntax

 
#include <string.h>

size_t strlen(const char *string);

Description

This function returns the number of characters in string.

Return Value

The length of the string.

Portability

ANSI/ISO C C89; C99
POSIX 1003.2-1992; 1003.1-2001

Example

 
if (strlen(fname) > PATH_MAX)
  invalid_file(fname);
