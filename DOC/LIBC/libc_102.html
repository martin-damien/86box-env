clearerr

Syntax

 
#include <stdio.h>

void clearerr(FILE *stream);

Description

This function clears the EOF and error indicators for the file stream.

Return Value

None.

Portability

ANSI/ISO C C89; C99
POSIX 1003.2-1992; 1003.1-2001

Example

 
clearerr(stdout);
