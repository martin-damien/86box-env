getdate

Syntax

 
#include <dos.h>

void getdate(struct date *);

Description

This function gets the current date. The return structure is as follows:

 
struct date {
  short da_year;
  char  da_day;
  char  da_mon;
};

See section setdate. See section gettime.

Return Value

None.

Portability

ANSI/ISO C No
POSIX No

Example

 
struct date d;
getdate(&d);
