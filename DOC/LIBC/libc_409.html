getpgrp

Syntax

 
#include <unistd.h>

int getpgrp(void);

Description

Gets the process group, which is currently the same as the pid.

Return Value

The process group.

Portability

ANSI/ISO C No
POSIX 1003.2-1992; 1003.1-2001
