_bios_memsize

Syntax

 
#include <bios.h>

unsigned _bios_memsize(void);

Description

This function returns the amount of system memory in 1K blocks (up to 640K).

Return Value

Size of memory (in K).

Portability

ANSI/ISO C No
POSIX No

Example

 
printf("This system has %d bytes of memory\n", _bios_memsize() * 1024);
