getwd

Syntax

 
#include <unistd.h>

char *getwd(char *buffer);

Description

Get the current directory and put it in buffer. The return value includes the drive specifier.

Return Value

buffer is returned.

Portability

ANSI/ISO C No
POSIX No

Example

 
char buf[PATH_MAX];
getwd(buf);
