bzero

Syntax

 
#include <string.h>

void bzero(void *pointer, int length);

Description

The data at pointer is filled with length zeros.

Return Value

None.

Portability

ANSI/ISO C No
POSIX No

Example

 
char foo[100];
bzero(foo,100);
