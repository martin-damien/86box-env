biosprint

Syntax

 
#include <bios.h>

int biosprint(int cmd, int byte, int port)

Description

command = 0

byte is sent to parallel port port.

command = 1

Parallel port port is reset and initialized.

command = 2

The status of parallel port port is returned.

 
7654 3210  Meaning

---- ---X  Timeout
---- -XX-  Unused
---- X---  I/O Error
---X ----  Selected
--X- ----  Out of paper
-X-- ----  Acknowledged
X--- ----  Idle

Return Value

The printer status.

Portability

ANSI/ISO C No
POSIX No

Example

 
while (*c)
  biosprint(0, *c++, 0);
