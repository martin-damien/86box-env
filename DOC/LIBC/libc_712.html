setstate

Syntax

 
#include <stdlib.h>

char *setstate(char *arg_state);

Description

Restores the random number generator (see section random) state from pointer arg_state to state array.

Return Value

Pointer to old state information.

Portability

ANSI/ISO C No
POSIX No
