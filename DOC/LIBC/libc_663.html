rewind

Syntax

 
#include <stdio.h>

void rewind(FILE *file);

Description

This function repositions the file pointer to the beginning of the file and clears the error indicator.

Return Value

None.

Portability

ANSI/ISO C C89; C99
POSIX 1003.2-1992; 1003.1-2001

Example

 
rewind(stdin);
