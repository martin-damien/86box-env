__dpmi_get_state_save_restore_addr

Syntax

 
#include <dpmi.h>

int __dpmi_get_state_save_restore_addr(__dpmi_raddr *_rm,
                                       __dpmi_paddr *_pm);

Description

Please refer to the DPMI Specification (see section DPMI Specification) for details on DPMI function call operation. Also see the DPMI Overview (see section DPMI Overview) for general information.

DPMI function AX = 0x0305

Read the spec for info.

Return Value

The number of bytes required to save state.
