__dpmi_reset_debug_watchpoint

Syntax

 
#include <dpmi.h>

int __dpmi_reset_debug_watchpoint(unsigned long _handle);

Description

Please refer to the DPMI Specification (see section DPMI Specification) for details on DPMI function call operation. Also see the DPMI Overview (see section DPMI Overview) for general information.

DPMI function AX = 0x0b03

Resets a watchpoint given its handle in _handle.

Return Value

-1 on error, else zero.

Portability

ANSI/ISO C No
POSIX No
