intdosx

Syntax

 
#include <dos.h>

int intdosx(union REGS *in, union REGS *out, struct SREGS *s);

Description

This function is just like int86x (see section int86x) except that the interrupt vector is 0x21.

Return Value

EAX

Portability

ANSI/ISO C No
POSIX No
