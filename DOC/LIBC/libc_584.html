movedatab

Syntax

 
#include <sys/movedata.h>

void _movedatab(unsigned, unsigned, unsigned, unsigned, size_t);

Description

Just like movedata, but all transfers are always 8-bit transfers.

Portability

ANSI/ISO C No
POSIX No
