tzsetwall

Syntax

 
#include <time.h>

void tzsetwall(void);

Description

This function sets up the time conversion information used by localtime (see section localtime) so that localtime returns the best available approximation of the local wall clock time.

Return Value

None.

Portability

ANSI/ISO C No
POSIX No
