intdos

Syntax

 
#include <dos.h>

int intdos(union REGS *in, union REGS *out);

Description

This function is just like int86 (see section int86x) except that the interrupt vector is 0x21.

Return Value

EAX

Portability

ANSI/ISO C No
POSIX No
