fchdir

Syntax

 
#include <unistd.h>

int fchdir(int fd);

Description

This function changes the current directory to the directory described by the file descriptor fd.

Return Value

Zero on success, else nonzero and errno set if error.

Portability

ANSI/ISO C No
POSIX 1003.2-1992; 1003.1-2001

Example

 
int fd;

fd = open("dir", O_RDONLY);
fchdir(fd);
