sys_nerr

Syntax

 
#include <errno.h>

extern int sys_nerr;

Description

This variable gives the number of error messages in sys_errlist (see section sys_errlist).

Portability

ANSI/ISO C No
POSIX No

Example

 
if (errno < sys_nerr)
  printf("Error: %s\n", sys_errlist[errno]);
