ScreenVisualBell

Syntax

 
#include <pc.h>

void  ScreenVisualBell(void);

Description

This function flashes the screen colors to produce the effect of "visual bell'. It does so by momentarily inverting the colors of every character on the screen.

Return Value

None.

Portability

ANSI/ISO C No
POSIX No

Example

 
ScreenVisualBell();
