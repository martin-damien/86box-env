isspace

Syntax

 
#include <ctype.h>

int isspace(int c);

Description

Tells if c is whitespace, that is, carriage return, newline, form feed, tab, vertical tab, or space.

Return Value

Nonzero if c is whitespace, else zero.

Portability

ANSI/ISO C C89; C99
POSIX 1003.2-1992; 1003.1-2001
