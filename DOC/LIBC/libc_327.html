findnext

Syntax

 
#include <dir.h>

int findnext(struct ffblk *ffblk);

Description

This finds the next file in the search started by findfirst. See section findfirst.

Return Value

Zero if there was a match, else nonzero.

Portability

ANSI/ISO C No
POSIX No
