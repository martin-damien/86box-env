fchown

Syntax

 
#include <unistd.h>

int fchown(int fd, uid_t owner, gid_t group);

Description

This function changes the ownership of the open file specified by fd to the user ID owner and group ID group.

This function does almost nothing under MS-DOS: it just checks if the handle fd is valid. This function can be hooked by File System Extensions (see section File System Extensions).

Return Value

This function returns zero if the handle is valid, non-zero otherwise.
