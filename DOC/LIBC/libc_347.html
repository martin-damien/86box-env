fputc

Syntax

 
#include <stdio.h>

int fputc(int character, FILE *file);

Description

This function writes the given character to the given file.

Return Value

The given character [0..255] or EOF.

Portability

ANSI/ISO C C89; C99
POSIX 1003.2-1992; 1003.1-2001

Example

 
fputc('\n', stdout);
