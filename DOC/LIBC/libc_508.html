iscntrl

Syntax

 
#include <ctype.h>

int iscntrl(int c);

Description

Tells if c is a control character.

Return Value

Nonzero if c is a control character, else zero.

Portability

ANSI/ISO C C89; C99
POSIX 1003.2-1992; 1003.1-2001
