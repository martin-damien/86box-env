strcasecmp

Syntax

 
#include <string.h>

int strcasecmp(const char *s1, const char *s2);

Description

This function compares the two strings, disregarding case.

Return Value

Zero if they're the same, nonzero if different, the sign indicates "order".

Portability

ANSI/ISO C No
POSIX No

Example

 
if (strcasecmp(arg, "-i") == 0)
  do_include();
