putchar

Syntax

 
#include <stdio.h>

int putchar(int c);

Description

This is the same as fputc(c, stdout). See section fputc.

Return Value

The character written.

Portability

ANSI/ISO C C89; C99
POSIX 1003.2-1992; 1003.1-2001

Example

 
while ((c = getchar()) != EOF)
  putchar(c);
