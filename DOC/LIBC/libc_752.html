strcat

Syntax

 
#include <string.h>

char *strcat(char *s1, const char *s2);

Description

This function concatenates s2 to the end of s1.

Return Value

s1

Portability

ANSI/ISO C C89; C99
POSIX 1003.2-1992; 1003.1-2001

Example

 
char buf[100] = "hello";
strcat(buf, " there");
