sscanf

Syntax

 
#include <stdio.h>

int sscanf(const char *string, const char *format, ...);

Description

This function scans formatted text from the string and stores it in the variables pointed to by the arguments. See section scanf.

Return Value

The number of items successfully scanned.

Portability

ANSI/ISO C C89; C99
POSIX 1003.2-1992; 1003.1-2001
