tell

Syntax

 
#include <io.h>

off_t tell(int file);

Description

This function returns the location of the file pointer for file.

Return Value

The file pointer, or -1 on error.

Portability

ANSI/ISO C No
POSIX No

Example

 
off_t q = tell(fd);
