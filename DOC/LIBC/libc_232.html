__dpmi_get_page_size

Syntax

 
#include <dpmi.h>

int __dpmi_get_page_size(unsigned long *_size);

Description

Please refer to the DPMI Specification (see section DPMI Specification) for details on DPMI function call operation. Also see the DPMI Overview (see section DPMI Overview) for general information.

DPMI function AX = 0x0604

Fills in the page size.

Return Value

-1 on error (16-bit host), else zero.

Portability

ANSI/ISO C No
POSIX No
