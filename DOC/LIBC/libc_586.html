movedataw

Syntax

 
#include <sys/movedata.h>

void _movedataw(unsigned, unsigned, unsigned, unsigned, size_t);

Description

Just like movedata, but all transfers are always 16-bit transfers, and the count is a count of transfers, not bytes.

Portability

ANSI/ISO C No
POSIX No
