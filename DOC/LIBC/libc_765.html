strlwr

Syntax

 
#include <string.h>

char *strlwr(char *string);

Description

This function replaces all upper case letters in string with lower case letters.

Return Value

The string.

Portability

ANSI/ISO C No
POSIX No

Example

 
char buf[100] = "Hello";
strlwr(buf);
