getppid

Syntax

 
#include <unistd.h>

int getppid(void);

Description

Get the parent process ID. Currently this is always 1, indicating that the parent process is no longer running.

Return Value

The parent process ID.

Portability

ANSI/ISO C No
POSIX 1003.2-1992; 1003.1-2001
