vscanf

Syntax

 
#include <stdio.h>

int vscanf(const char *format, va_list arguments);

Description

This function scans formatted text from stdin and stores it in the variables pointed to by the arguments. See section scanf. See section vfscanf.

Return Value

The number of items successfully scanned.

Portability

ANSI/ISO C No
POSIX No
