_go32_dpmi_remaining_virtual_memory

Syntax

 
#include <dpmi.h>

unsigned long _go32_dpmi_remaining_virtual_memory(void);

Description

Returns the amount of virtual memory that is still available in the system.

Return Value

The amount in bytes.
