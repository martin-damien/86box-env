strtoull

Syntax

 
#include <stdlib.h>

unsigned long long int strtoull(const char *s, char **endp, int base);

Description

This is just like strtoll (see section strtoll) except that the result is unsigned.

Return Value

The value.

Portability

ANSI/ISO C C99; not C89
POSIX 1003.1-2001; not 1003.2-1992

Example

 
printf("Enter a number: "); fflush(stdout);
gets(buf);
char *bp;
printf("The value is %llu\n", strtoull(buf, &bp, 0));
