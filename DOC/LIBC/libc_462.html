hasmntopt

Syntax

 
#include <mntent.h>

char *hasmntopt(const struct mntent *mnt, const char *opt);

Description

This function scans the mnt_opts field of the mntent structure pointed to by mnt for a substring that matches opt. See section getmntent.

Return Value

This function returns the address of the substring if a match is found, or NULL otherwise.
