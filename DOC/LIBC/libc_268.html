__dpmi_set_processor_exception_handler_vector

Syntax

 
#include <dpmi.h>

int __dpmi_set_processor_exception_handler_vector(
        int _vector, __dpmi_paddr *_address
);

Description

Please refer to the DPMI Specification (see section DPMI Specification) for details on DPMI function call operation. Also see the DPMI Overview (see section DPMI Overview) for general information.

DPMI function AX = 0x0203

This function installs a handler for protected mode exceptions (not interrupts). You must pass a selector:offset pair.

Return Value

-1 on error, else zero.

Portability

ANSI/ISO C No
POSIX No
