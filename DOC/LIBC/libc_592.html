nan

Syntax

 
#include <math.h>

double nan(const char *tagp);

Description

nan returns a quiet NaN with contents indicated by tagp.

Return Value

The quiet NaN.

If quiet NaNs are not supported, zero is returned. DJGPP supports quiet NaNs.

Portability

ANSI/ISO C C99; not C89

Example

 
double d = nan("0x1234");
