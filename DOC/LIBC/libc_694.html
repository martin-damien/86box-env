setcbrk

Syntax

 
#include <dos.h>

void setcbrk(int check);

Description

Set the setting of the Ctrl-Break checking flag in MS-DOS. If check is zero, checking is not done. If nonzero, checking is done.

Return Value

None.

Portability

ANSI/ISO C No
POSIX No
