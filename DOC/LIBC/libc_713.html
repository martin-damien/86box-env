settime

Syntax

 
#include <dos.h>

void settime(struct time *ptr);

Description

This function sets the current time.

For the description of struct time, see gettime. Also see setdate.

Return Value

None.

Portability

ANSI/ISO C No
POSIX No

Example

 
struct time t;
settime(&t);
