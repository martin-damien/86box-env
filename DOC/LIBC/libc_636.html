raise

Syntax

 
#include <signal.h>

int	raise(int sig);

Description

This function raises the given signal sig. See section the list of possible signals.

Return Value

0 on success, -1 for illegal value of sig.

Portability

ANSI/ISO C C89; C99
POSIX 1003.2-1992; 1003.1-2001
