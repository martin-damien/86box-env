getc

Syntax

 
#include <stdio.h>

int getc(FILE *file);

Description

Get one character from file.

Return Value

The character ([0..255]) or EOF if eof or error.

Portability

ANSI/ISO C C89; C99
POSIX 1003.2-1992; 1003.1-2001

Example

 
int c;
while ((c=getc(stdin)) != EOF)
  putc(c, stdout);
