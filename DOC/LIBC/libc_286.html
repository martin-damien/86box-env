ecvt

Syntax

 
#include <stdlib.h>

char * ecvt (double value, int ndigits, int *decpt, int *sign)

Description

This function converts the value into a null-terminated string, and returns a pointer to that string.

ecvt works exactly like ecvtbuf (see section ecvtbuf), except that it generates the string in an internal static buffer which is overwritten on each call.

Return Value

A pointer to the generated string.

Portability

ANSI/ISO C No
POSIX No
