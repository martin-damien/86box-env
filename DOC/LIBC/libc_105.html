_close

Syntax

 
#include <io.h>

int _close(int fd);

Description

This is a direct connection to the MS-DOS close function call, int 0x21, %ah = 0x3e. This function can be hooked by the See section File System Extensions. If you don't want this, you should use See section _dos_close.

Return Value

Zero if the file was closed, else nonzero.

Portability

ANSI/ISO C No
POSIX No
