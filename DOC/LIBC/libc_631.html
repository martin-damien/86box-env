puts

Syntax

 
#include <stdio.h>

int puts(const char *string);

Description

This function writes string to stdout, and then writes a newline character.

Return Value

Nonnegative for success, or EOF on error.

Portability

ANSI/ISO C C89; C99
POSIX 1003.2-1992; 1003.1-2001

Example

 
puts("Hello, there");
