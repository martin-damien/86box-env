isblank

Syntax

 
#include <ctype.h>

int isblank(int c);

Description

Tells if c is a blank character. A blank character is used to separate words, e.g.: ` ' or `\t'.

Return Value

Nonzero if c is a blank character, else zero.

Portability

ANSI/ISO C C99; not C89
POSIX 1003.2-1992; 1003.1-2001
