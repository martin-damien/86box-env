toupper

Syntax

 
#include <ctype.h>

int toupper(int c);

Description

This function returns c, converting it to upper case if it is lower case. See section tolower.

Return Value

The upper case letter.

Portability

ANSI/ISO C C89; C99
POSIX 1003.2-1992; 1003.1-2001

Example

 
for (i=0; buf[i]; i++)
  buf[i] = toupper(buf[i]);
