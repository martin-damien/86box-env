fclose

Syntax

 
#include <stdio.h>

int fclose(FILE *file);

Description

This function closes the given file.

Return Value

Zero on success, else EOF.

Portability

ANSI/ISO C C89; C99
POSIX 1003.2-1992; 1003.1-2001

Example

 
FILE *f = fopen("data", "r");
fprintf(f, "Hello\n");
fclose(f);
