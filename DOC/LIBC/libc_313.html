feof

Syntax

 
#include <stdio.h>

int feof(FILE *file);

Description

This function can be used to indicate if the given file is at the end-of-file or not.

Return Value

Nonzero at end-of-file, zero otherwise.

Portability

ANSI/ISO C C89; C99
POSIX 1003.2-1992; 1003.1-2001

Example

 
while (!feof(stdin))
  gets(line);
