fprintf

Syntax

 
#include <stdio.h>

int fprintf(FILE *file, const char *format, ...);

Description

Prints formatted output to the named file. See section printf.

Return Value

The number of characters written.

Portability

ANSI/ISO C C89; C99
POSIX 1003.2-1992; 1003.1-2001
