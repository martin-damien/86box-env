__dpmi_set_debug_watchpoint

Syntax

 
#include <dpmi.h>

int __dpmi_set_debug_watchpoint(__dpmi_meminfo *_info, int _type);

Description

Please refer to the DPMI Specification (see section DPMI Specification) for details on DPMI function call operation. Also see the DPMI Overview (see section DPMI Overview) for general information.

DPMI function AX = 0x0b00

Set a debug breakpoint. Type is 0 for execute, 1 for write, and 2 for access. Fill in address and size (1,2,4 bytes). Server fills in handle.

Return Value

-1 on error, else zero.

Portability

ANSI/ISO C No
POSIX No
