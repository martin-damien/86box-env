getgroups

Syntax

 
#include <unistd.h>

int getgroups(int size, gid_t *grouplist);

Description

This function always returns zero. It exists to assist porting from Unix.

Return Value

Zero.

Portability

ANSI/ISO C No
POSIX 1003.2-1992; 1003.1-2001
