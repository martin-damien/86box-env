ScreenMode

Syntax

 
#include <pc.h>

int  ScreenMode(void);

Description

This function reports the current video mode as known to the system BIOS. It does so by accessing the byte at absolute address 40:49h.

Return Value

The video mode.

Portability

ANSI/ISO C No
POSIX No

Example

 
video_mode = ScreenMode();
