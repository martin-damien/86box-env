globfree

Syntax

 
#include <glob.h>

void globfree(glob_t *pglob);

Description

Frees the memory associated with pglob, which should have been allocated by a call to glob (see section glob).

Portability

ANSI/ISO C No
POSIX 1003.2-1992; 1003.1-2001
