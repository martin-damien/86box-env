pause

Syntax

 
#include <unistd.h>

int pause(void);

Description

This function just calls __dpmi_yield() (see section __dpmi_yield) to give up a slice of the CPU.

Return Value

Zero.

Portability

ANSI/ISO C No
POSIX 1003.2-1992; 1003.1-2001
