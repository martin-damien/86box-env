putc

Syntax

 
#include <stdio.h>

int putc(int c, FILE *file);

Description

This function writes one character to the given file.

Return Value

The character written.

Portability

ANSI/ISO C C89; C99
POSIX 1003.2-1992; 1003.1-2001

Example

 
while ((c=getc(stdin)) != EOF)
  putc(c, stdout);
