rawclock

Syntax

 
#include <time.h>

unsigned long rawclock(void);

Description

Returns the number of clock tics (18.2 per second) since midnight.

Return Value

The number of tics.

Portability

ANSI/ISO C No
POSIX No

Example

 
/* wait 1/4 second */
int i = rawclock()+5;
while (rawclock()<i);
