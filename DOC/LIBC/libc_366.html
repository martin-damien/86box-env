ftell

Syntax

 
#include <stdio.h>

long ftell(FILE *file);

Description

Returns the current file position for file. This is suitable for a future call to fseek.

Return Value

The file position, or -1 on error.

Portability

ANSI/ISO C C89; C99
POSIX 1003.2-1992; 1003.1-2001

Example

 
long p = ftell(stdout);
