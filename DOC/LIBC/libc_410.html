getpid

Syntax

 
#include <unistd.h>

int getpid(void);

Description

Get the process ID, which uniquely identifies each program running on the system.

Return Value

The process ID.

Portability

ANSI/ISO C No
POSIX 1003.2-1992; 1003.1-2001
