tolower

Syntax

 
#include <ctype.h>

int tolower(int c);

Description

This function returns c, converting it to lower case if it is upper case. See section toupper.

Return Value

The lower case letter.

Portability

ANSI/ISO C C89; C99
POSIX 1003.2-1992; 1003.1-2001

Example

 
for (i=0; buf[i]; i++)
  buf[i] = tolower(buf[i]);
