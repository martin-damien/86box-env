isalnum

Syntax

 
#include <ctype.h>

int isalnum(int c);

Description

Tells if c is any letter or digit.

Return Value

Nonzero if c is a letter or digit, else zero.

Portability

ANSI/ISO C C89; C99
POSIX 1003.2-1992; 1003.1-2001
