rewinddir

Syntax

 
#include <dirent.h>

void rewinddir(DIR *dir);

Description

This function resets the position of the dir so that the next call to readdir (see section readdir) starts at the beginning again.

Return Value

None.

Portability

ANSI/ISO C No
POSIX 1003.2-1992; 1003.1-2001

Example

 
DIR *d = opendir(".");
rewinddir(d);
