getcbrk

Syntax

 
#include <dos.h>

int getcbrk(void);

Description

Get the setting of the Ctrl-C checking flag in MS-DOS.

See section setcbrk.

Return Value

0 if not checking, 1 if checking.

Portability

ANSI/ISO C No
POSIX No
