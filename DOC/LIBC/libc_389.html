getdisk

Syntax

 
#include <dir.h>

int getdisk(void);

Description

Gets the current disk (0=A).

See section setdisk.

Return Value

The current disk number.

Portability

ANSI/ISO C No
POSIX No

Example

 
printf("This drive is %c:\n", getdisk() + 'A');
