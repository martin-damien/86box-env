vsscanf

Syntax

 
#include <stdio.h>

int vsscanf(const char *string, const char *format, va_list arguments);

Description

This function scans formatted text from the string and stores it in the variables pointed to by the arguments. See section scanf. See section vfscanf.

Return Value

The number of items successfully scanned.

Portability

ANSI/ISO C No
POSIX No
