cfsetospeed

Syntax

 
#include <termios.h>

int cfsetospeed (struct termios *termiosp, speed_t speed);

Description

This function sets the output line speed stored in the structure termiosp to speed. See section Termios functions, for more details about this structure and the baudrate values it supports.

Note that the termios emulation handles console only, and that the baudrate values have no effect in this implementation.

Return Value

Zero on success, nonzero on failure.

Portability

ANSI/ISO C No
POSIX 1003.2-1992; 1003.1-2001
