setgrent

Syntax

 
#include <grp.h>

void setgrent(void);

Description

This function should be called before any call to getgrent, getgrgid, or getgrnam, to start searching the groups' list from the beginning. See section getgrent.

Return Value

None.

Portability

ANSI/ISO C No
POSIX No
