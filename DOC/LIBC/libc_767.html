strncat

Syntax

 
#include <string.h>

char *strncat(char *s1, const char *s2, size_t max);

Description

This function concatenates up to max characters of s2 to the end of s1.

Return Value

s1

Portability

ANSI/ISO C C89; C99
POSIX 1003.2-1992; 1003.1-2001

Example

 
strncat(fname, extension, 4);
