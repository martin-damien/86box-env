kill

Syntax

 
#include <signal.h>

int	kill(pid_t _pid, int _sig);

Description

If _pid is the current getpid(), the given _sig is raised with raise.

Return Value

-1 on error, else zero.

Portability

ANSI/ISO C No
POSIX 1003.2-1992; 1003.1-2001
