toascii

Syntax

 
#include <ctype.h>

int toascii(int c);

Description

This function strips the high bit of c, forcing it to be an ASCII character.

Return Value

The ASCII character.

Portability

ANSI/ISO C No
POSIX No

Example

 
for (i=0; buf[i]; i++)
  buf[i] = toascii(buf[i]);
