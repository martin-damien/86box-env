/=====================================\
|| 86BOX/DOS development environment ||
\=====================================/

This repository contains my 86Box / FreeDos development environment.


Folders
-------

86BOX		86Box application folder
APP		Application to be installed in the machines
DISKS		Machines' disks folder
DOC		Various documentations
FLOPPIES	Various floppies images
GAMES		Games to be installed in the machines
MACHINES	Various machines 86Box configurations
OS		Operating systems disk images
SHADERS		Some shaders that can be applied to the machines


Current setup
-------------

I actually use a simple Pentium II machine (MACHINES/FreeDos) with two disks:

1st disk (0:0) 5G

	C:	FreeDos 1.4
	
2nd disk (1:0) 32G each in FAT32

	D:	Development files
	E:	Backups (mainly projects)
	F:	Tools (manually installed, like DJGPP)
	G:	Games

External disks

	A:	3.5" 1.44M floppy drive
	H: 	(0:1) CD-Rom


About the repository content
----------------------------

For space consumption and/or legal reasons, some files are not versioned:

- Proprietary softwares (applications, games, softwares, ...)
- 86box binaries (you can download them by yourself freely)
- 86box roms (same reason + not sure if it is really legal or not)
- My disk images (hard drives, floppies, ...) are personnal and too big
- Docs that are not "free to download" (copyrights are untouched for versioned ones)
