_stklen

Syntax

 
extern int _stklen;

Description

This variable sets the minimum stack length that the program requires. Note that the stack may be much larger than this. This value should be set statically, as it is only used at startup.

Portability

ANSI/ISO C No
POSIX No

Example

 
int _stklen = 256000;
