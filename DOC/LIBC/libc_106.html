closedir

Syntax

 
#include <dirent.h>

int closedir(DIR *dir);

Description

This function closes a directory opened by opendir (see section opendir).

Return Value

Zero on success, nonzero if dir is invalid.

Portability

ANSI/ISO C No
POSIX 1003.2-1992; 1003.1-2001
