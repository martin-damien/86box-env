rmdir

Syntax

 
#include <unistd.h>

int rmdir(const char *dirname);

Description

This function removes directory dirname. The directory must be empty.

Return Value

Zero if the directory was removed, nonzero on failure.

Portability

ANSI/ISO C No
POSIX 1003.2-1992; 1003.1-2001

Example

 
rmdir("/tmp/datadir");
