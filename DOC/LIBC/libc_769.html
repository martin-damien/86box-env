strncpy

Syntax

 
#include <string.h>

char *strncpy(char *s1, const char *s2, size_t max);

Description

This function copies up to max characters of s2 into s1.

Return Value

s1

Portability

ANSI/ISO C C89; C99
POSIX 1003.2-1992; 1003.1-2001

Example

 
char buf[100];
strncpy(buf, arg, 99);
