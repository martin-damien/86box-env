ceil

Syntax

 
#include <math.h>

double ceil(double x);

Description

This function computes the smallest integer greater than or equal to x.

Return Value

The smallest integer value greater than or equal to x.

Portability

ANSI/ISO C C89; C99
POSIX 1003.2-1992; 1003.1-2001
