setdisk

Syntax

 
#include <dir.h>

int setdisk(int drive);

Description

This function sets the current disk (0=A).

See also getdisk.

Return Value

The highest drive actually present that the system can reference.

Portability

ANSI/ISO C No
POSIX No

Example

 
printf("There are %d drives\n", setdisk(getdisk()));
