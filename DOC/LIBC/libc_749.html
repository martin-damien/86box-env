stpcpy

Syntax

 
#include <string.h>

char *stpcpy(char *_dest, const char *_src);

Description

Like strcpy (see section strcpy), but return value different.

Return Value

Returns a pointer to the trailing NUL in dest.

Portability

ANSI/ISO C No
POSIX No
