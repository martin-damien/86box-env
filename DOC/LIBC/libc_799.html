sys_errlist

Syntax

 
#include <errno.h>

extern char *sys_errlist[];

Description

This array contains error messages, indexed by errno, that describe the errors.

Portability

ANSI/ISO C No
POSIX No

Example

 
printf("Error: %s\n", sys_errlist[errno]);
