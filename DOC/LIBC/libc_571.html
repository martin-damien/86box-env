mkfifo

Syntax

 
#include <sys/stat.h>

int mkfifo(const char *path, mode_t mode);

Description

This function is provided only to assist in porting from Unix. It always returns an error condition.

Portability

ANSI/ISO C No
POSIX 1003.2-1992; 1003.1-2001
