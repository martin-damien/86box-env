int386x

Syntax

 
#include <dos.h>

int int386x(int ivec, union REGS *in, union REGS *out,
            struct SREGS *seg);

Description

This function is equal to int86x. See int86, for further description.

Return Value

The value of EAX is returned.

Portability

POSIX No
