modfl

Syntax

 
#include <math.h>

long double modfl(long double x, long double *pint);

Description

modfl breaks down x into its integer portion (which it stores in *pint) and the remaining fractional portion, which it returns.

Return Value

The fractional portion.

Portability

ANSI/ISO C No
POSIX No
