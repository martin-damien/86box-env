strcpy

Syntax

 
#include <string.h>

char *strcpy(char *s1, const char *s2);

Description

This function copies s2 into s1.

Return Value

s1

Portability

ANSI/ISO C C89; C99
POSIX 1003.2-1992; 1003.1-2001

Example

 
char buf[100];
strcpy(buf, arg);
