strupr

Syntax

 
#include <string.h>

char *strupr(char *string);

Description

This function converts all lower case characters in string to upper case.

Return Value

string

Portability

ANSI/ISO C No
POSIX No

Example

 
char buf[] = "Foo!";
strupr(buf);
