ScreenUpdateLine

Syntax

 
#include <pc.h>

void  ScreenUpdateLine(void *buf, int row);

Description

This function writes the contents of buf to the screen line number given in row (the topmost line is row 0), on the primary screen.

Return Value

None.

Portability

ANSI/ISO C No
POSIX No

Example

 
ScreenUpdateLine(line_buf, 10);
