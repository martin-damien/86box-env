nanf

Syntax

 
#include <math.h>

float nanf(const char *tagp);

Description

nanf returns a quiet NaN with contents indicated by tagp.

Return Value

The quiet NaN.

If quiet NaNs are not supported, zero is returned. DJGPP supports quiet NaNs.

Portability

ANSI/ISO C C99; not C89

Example

 
float f = nanf("0x1234");
