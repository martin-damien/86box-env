sleep

Syntax

 
#include <unistd.h>

unsigned sleep(unsigned seconds);

Description

This function causes the program to pause for seconds seconds.

Return Value

The number of seconds that haven't passed (i.e. always zero)

Portability

ANSI/ISO C No
POSIX 1003.2-1992; 1003.1-2001

Example

 
sleep(5);
