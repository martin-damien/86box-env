isgraph

Syntax

 
#include <ctype.h>

int isgraph(int c);

Description

Tells if c is a visible printing character. Space is not included.

Return Value

Nonzero if c is a visible printing character, else zero.

Portability

ANSI/ISO C C89; C99
POSIX 1003.2-1992; 1003.1-2001
